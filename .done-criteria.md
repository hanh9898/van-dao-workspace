# Done criteria — four mechanisms against repeated agent mistakes

Written **before** the work starts. `bin/check-turn.py` (a `Stop` hook) blocks the turn while any
`- [ ]` remains. An item dropped on purpose is written `- [~]` with the reason — dropping with a
reason is a decision, dropping in silence is forgetting.

## The method that was specified

The user asked how to make sure these mistakes do not recur, and required **researching how other
agent harnesses handle it** (done: Martin Fowler, HumanLayer, build-verify loop, Faros). Then asked
"why not all three" when I had narrowed four mechanisms down to two on my own — so the scope is
**all four**, and narrowing it is exactly the failure under discussion.

Then: the four new files were written in Vietnamese, in the middle of a refactor that had already
committed the whole system to English. That is pitfall #4 in the very ledger being written. Scope
now also covers rewriting them.
