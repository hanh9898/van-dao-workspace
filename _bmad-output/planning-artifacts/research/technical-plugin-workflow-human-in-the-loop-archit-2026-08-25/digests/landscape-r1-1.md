## Leads worth chasing in a follow-up round

- **Microsoft Agent Framework merger (AutoGen + Semantic Kernel → v1.0, ~April 2026)**: only sourced via an aggregator in this pass. A primary Microsoft/Azure engineering blog should be pulled to confirm version, date, and whether it materially changes HITL checkpoint APIs.
- **Claude Code / plugin-and-extension-specific HITL patterns**: this pass found strong evidence for orchestration-engine-level HITL (LangGraph, Temporal) and protocol-level standards (MCP, A2A), but did not surface primary-source material specifically on *plugin/extension architectures for developer tools* (e.g., how VS Code, Claude Code, or JetBrains-style plugin systems structure approval checkpoints within an IDE/CLI plugin, as opposed to a backend workflow engine). Worth a dedicated search pass.
- **AGENTS.md** (OpenAI-originated, now also an Agentic AI Foundation founding project alongside MCP and Block's `goose`) appeared as a third consolidating standard but wasn't explored — could be relevant if the target plugin needs a standardized "agent instructions" convention.
- **Contradiction/tension to probe**: aggregator sources assert protocol-layer consolidation is essentially settled (MCP/A2A "won"), but the MCP 2026-07-28 spec was still labeled a "release candidate" as of that date per search snippets — worth checking whether the spec has since finalized, since that bears on the "consolidating vs. still churning" question at the protocol level itself, not just the framework layer.
- **NIST AI RMF / EU AI Act Article 14** were mentioned as regulatory drivers for demonstrable human oversight in HITL design — not independently verified here, but relevant if the decision has a compliance dimension.

- A second independent (non-vendor) source for the "controlled autonomy" framing as a named industry consensus term — current sourcing is vendor-blog only.
